# Bioinformatics-scripts

Collection of Python scripts to perform simple bioinformatics tasks including post-processing of results data from well-known tools.

## Features

- **FASTA**: FASTA file processing for DNA/protein sequence translation, sequence statistics, protein diversity analysis.
- **Download**: Sequence data downloads.
- **SNP**: SNP extraction and analysis.
- **MLST**: Post-processing of MLST results.
- **Figures**: Scripts to create visualizations.
- **BAM**: BAM file processing utilities.
